# SAM3TGNet

Official repository for **“SAM3TGNet: A SAM3 Feature Encoding and Global Context Spatiotemporal Attention-Enhanced Change Detection Method for Optical Remote Sensing Images.”**

SAM3TGNet is a deep learning method for bitemporal optical remote sensing image change detection. The method integrates frozen SAM3 multiscale spatial features, cross-temporal feature interaction, spatiotemporal feature fusion, global context spatial attention, and a dynamically weighted loss.
